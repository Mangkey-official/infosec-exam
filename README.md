# 🛡️ SecuMaster - 정보보안기사 필기 랜덤 기출 & 요약본 생성 시스템

정보보안기사 필기 수험생을 위해 **역대 기출 기반 랜덤 모의고사 생성**, **AI/스마트 기출 변형 출제**, **오답 연동 핵심 요약본 자동 생성**을 제공하는 웹 애플리케이션입니다.

## ✨ 주요 기능

1. **📊 5대 과목별 대시보드 & 취약점 분석**
   - 1과목(시스템 보안), 2과목(네트워크 보안), 3과목(애플리케이션 보안), 4과목(정보보안 일반), 5과목(정보보안 관리 및 법규) 성취도 및 과락(40점)/합격(60점) 지표 분석
2. **🎲 랜덤 기출 & 변형 모의고사 생성기**
   - 과목 선택, 문항 수(5~50문항), 출제 기준(전체 랜덤 / 미풀이 우선 / 오답만 / 북마크만) 설정
   - **선지(보기) 순서 랜덤 셔플**로 단순 답 번호 암기 방지
   - **학습 모드**(선택 즉시 정답·해설·한 줄 요점 확인) 및 **실전 시험 모드**(타이머 작동 및 종료 후 일괄 채점)
   - 문제 풀이 중 **[⚡ 이 문제 변형 출제]** 버튼으로 즉시 응용 변형 문제 생성 및 풀이
3. **📝 맞춤형 핵심 요약본 생성기 & 암기 가림막 모드**
   - 과목별 빈출 핵심 이론 요약 + 기출 한 줄 암기 요점 + **내가 틀린 오답 요점 상단 자동 배치**
   - **🧠 핵심키워드 암기 가림막 모드**: 요약본 내 중요 키워드를 가리고 클릭해서 확인하는 플래시카드 학습
   - 마크다운(`.md`) 다운로드, 클립보드 복사, 인쇄/PDF 저장 지원
4. **➕ 기출 텍스트 자동 파서 & AI 문제 생성**
   - PDF/복원 기출 텍스트를 붙여넣으면 문제·보기·정답·해설·요점을 자동 분리하여 DB에 등록
   - Gemini API 연동 실시간 AI 변형 문제 생성 + 오프라인 내장 스마트 변형 생성기 지원
